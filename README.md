# SoundCloud Track ID Finder
## 概要＆使い方
WIKIWIKIのSoundCloudプラグインに要求されるトラックIDを簡単に取得できます。
1. 拡張機能を有効にした上で、ブラウザでSoundCloudの任意の楽曲のページを開きます。
2. 拡張機能のポップアップを開きます。
3. ボタン「トラックをIDを取得」を押すと、クリップボードにトラックIDがコピーされます。

## インストール方法
### Microsoft Edge
1. [Releases](https://github.com/Kosh-Unkesh/soundcloud-track-id-finder/releases)からZIPファイルをダウンロードして展開。
2. アドレスバーに`edge://extensions`と入力して移動。
3. 開発者モードを有効化。
4. 「展開して読み込み」から展開したフォルダを選択。
